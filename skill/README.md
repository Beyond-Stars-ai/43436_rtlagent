# 技能包说明

本目录下的两个技能包都是**可选的按需资源**：模型通过 `skill` 工具主动加载，不加载也能完成大部分题目。
它们不是"必须执行的流程"，而是"已知踩坑点的结构化清单"。

> **启用状态（与实物一致）**：本目录实际**启用 1 个** DSH 技能（`verilog-2001-syntax/SKILL.md`）。
> `rtl-module-interface-contract` 的文件名是 `SKILL.md.disabled`，**默认停用**：它依赖官方测试台的
> elaborate 报错（`cannot find port` 等）作为触发信号，而本赛道评测前不公开参考测试台，本地永远
> 不出现该信号；实测启用后对 156 题无增益。原文保留在仓库内仅作参考，README 第 2 节说明其适用边界。
> 方案真正生效的领域知识在 `agent/prompt4/`（16 条按题拼装的自查条目），两者合计构成本队技能包。


## 使用前提

两处硬约束统一放在 `agent/AGENTS.md`（常驻注入，每轮生效）：

1. 顶层模块名 `TopModule`，端口名/方向/位宽与题面逐字一致。
2. 判分器以 `xvlog -sv` 编译 `solution.v`，写完必须跑 `xvlog` + `xelab` 直到 0 错。

技能包**只补充 `AGENTS.md` 写不下的细节**，避免主提示词过长。

---

## 1. `verilog-2001-syntax`

**适用条件**

- `xvlog` 报出以下四类错误之一：`VRFC 10-2989`、`VRFC 10-3236`、`VRFC 10-9336`、`VRFC 10-9195`
- 模型在 Verilog-2001 与 SystemVerilog 写法之间混用，导致"能看懂但编译不过"
- 需要一份"错误码 → 正确写法"的对照表

**不适用条件**

- 判分器其实接受 SystemVerilog（`xvlog -sv`）。**本技能包不禁止 `always_ff` / `always_comb` /
  `typedef`**——早期版本曾写"禁用 SV"，那是错误结论，已删除。
- 题目错在理解（功能算错）而非语法：本技能包对 L2 仿真不匹配没有帮助。
- 模型已经能一次编译通过：加载它属于纯浪费（约 400 token）。

**内容**：四条红线的错误示例与正确写法，每条带 Vivado 报错码，便于日志比对。

---

## 2. `rtl-module-interface-contract`

来源：AMD 官方随基础镜像提供的技能包，原文保留（MIT，见文件头版权声明）。

**适用条件**

- **能拿到官方测试台的 elaborate 报错**（`VRFC 10-3180`、`cannot find port`、
  `not found while processing module instance`），需要按报错反推端口签名
- 需要一份"接口契约"的系统性检查清单（模块名 / 端口存在性 / 方向位宽 / 头部可解析 / 不含测试台内容）
- 需要模板化的诊断报告输出

**不适用条件**

- **本赛道正式评测不公开参考测试台**（`tasks/README.md`：参考实现与测试台在评测前不公开）。
  因此该技能包依赖的触发信号（testbench elaborate 报错）在本地**永远不出现**，模型没有理由加载它。
- 本方案要求"只输出代码"（`AGENTS.md` 第 5 节），而该技能包的输出格式是诊断报告，
  两者叠加会让模型产出与交付物无关的内容。
- 体积 9.5 KB（约 2,700 token），单次加载约为上下文窗口的 6%。**实测 156 题中只被加载 8 次**，
  性价比低。

**结论**：保留原文件供参考与合规（官方技能包），但**不建议主动加载**；接口问题改用
`AGENTS.md` 的"接口即契约"条款 + 编译器报错处理。

---

## 3. 组合使用建议

| 场景 | 建议 |
| :--- | :--- |
| 编译报错，错误码属于上述四类 | 加载 `verilog-2001-syntax`，照表修改 |
| 编译通过但仿真不匹配 | **两个技能包都帮不上**，应回到题面重新推导功能 |
| 端口疑似写错但无测试台报错 | 按 `AGENTS.md` 第 2 节逐字核对题面，不加载 `rtl-module-interface-contract` |

## 4. 复用说明（给其他队伍）

- 两个技能包都与具体模型无关，换成任何能调用工具的模型都可用。
- `verilog-2001-syntax` 的错误码来自 Vivado 2026.1 / `xvlog`，其他版本可能编号不同，但错误语义一致。
- 若你的评测环境**不提供** `xvlog`，这两个技能包都不适用。
